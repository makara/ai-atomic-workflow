# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities through this repository's GitHub private security advisories (Security → Report a vulnerability). Do not open a public issue for a suspected vulnerability.

Include in the report:

- what you observed and where (package, file, or endpoint);
- the smallest reproduction you have;
- the affected package and version;
- any impact you can already see.

Reports are acknowledged as fast as we can and a fix and disclosure window is coordinated with you.

## Scope

In scope: the published library modules (`agentic-graphjs`, `atomic-graph-format`), the workflow estate packages (`graph-workflow`, the `workflow-*` family), the application face (`awf`), and the gate scripts in this repository.

Out of scope: issues in third-party dependencies (report those upstream; tell us if this repository is affected), and findings that require a compromised local environment.
