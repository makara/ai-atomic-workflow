# Alignment with writing-for-agents

Every Content Quality Metrics rule maps to a wfa concept; gap markers note supplements (norms wfa lacks) or corrections (patterns wfa misses). Corrections are supplements, never replacements.

## Notes

- Same-name vocabulary (sprawl, no-op, negation, pruning, completion criterion, context pointer) maps directly - wfa retains the same lexicon.
- wfa new levers absorbed into Content Quality Metrics: leading words, two loads, demand/legwork, premature completion, co-location, sediment, environment-as-source-of-truth.
- The mapping's first pair mirrors the governing order in Content Quality Metrics: placement (Loading Efficiency) first, size diagnostics (Length Bands) second. Remaining rows follow SKILL.md section order, not a strict mirror.
